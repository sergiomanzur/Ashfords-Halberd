# Player guide

See the current [Ashford's Halberd README](../../README.md) and
[packaged player instructions](../../docs/campaign-package-readme.md).

The campaign is single-player. Run AshfordsHalberd.exe, select your USA PS2
SLUS-20184 ISO in the launcher and choose Play Campaign. Preferences and saves
normally live in %APPDATA%\AshfordsHalberd\Campaign. F1 and the game's OPTION >
ENHANCED OPTIONS menu share preferences and Cheats; F2 opens Cheats directly.

This directory retains technical documentation for the inherited renderer,
file formats and controls. The parent README is authoritative for this build's
launcher, packaging and validation state.
