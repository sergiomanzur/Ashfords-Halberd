Ashford's Halberd - Windows development 0.2

This is a development foundation, not a playable game build yet.

Double-click AshfordsHalberd.exe. On first use, choose your own unmodified
Resident Evil: Code Veronica X USA PS2 ISO (SLUS-20184). The application
validates and imports the disc locally. Allow about 2 GB for imported assets.
No ISO or game assets are distributed with this package.

After import, the main menu is available. New Game is in development.
Room Viewer displays retail room geometry and original camera snapshots.
Up/Down changes rooms, Left/Right changes cameras, Enter/A changes the camera
view, and Escape/B returns to the menu. Controller D-pad and footer mouse
buttons also work. These selections persist in the INI.
Options controls resolution, window mode, and VSync. Game Data changes the ISO.
Use the mouse, arrows/Enter/Escape, or controller D-pad/A/B.
Corridor Preview runs Claire's native movement, animation, collision, props
and room events in the original corridor. WASD/arrows or the controller's
left stick/D-pad move; Shift/controller X runs; Escape/controller B returns.
This preview does not yet include interactions, travel, combat or saves.

Settings: %LOCALAPPDATA%\AshfordsHalberd\AshfordsHalberd.ini
Assets:   %LOCALAPPDATA%\AshfordsHalberd\assets

The executable runs natively on Windows x64. Python and an emulator are not
required. The viewer uses a native software renderer with approximate lighting.
The corridor preview includes animated actors and movement. Interactions,
connected-room travel, combat, inventory, audio and save/load remain pending. Player camera
tracking and the modern over-the-shoulder camera remain future milestones.
Third-party notices are in the licenses folder.
